Arbre de décision · architecture conditionnelle

Le bon traitement au bon moment, selon ce que l'enseignant apporte

HAPI choisit dynamiquement le chemin le plus frugal selon le type de corpus. L'IA n'intervient qu'en dernier recours, après que les traitements JS locaux ont échoué. Une chaîne ~95 % souveraine (ILaaS + Albert API), orchestrée pour générer des activités H5P ancrées dans les programmes officiels du Bulletin Officiel.

Périmètre de modération actuel : une modération via n8n s'applique uniquement sur les contenus visuels (OCR / Parse / Vision). Les autres chemins — scraping web, VTT, Whisper, texte direct, prompts IA, sorties IA — ne passent à ce jour par aucun filtre.

Les services orchestrés par n8n (~95 % souverain)

n8n est le chef d'orchestre central : tous les appels IA transitent par ses webhooks (hapi_albert, hapi-image, hapi-audio, hapi-ocr, hapi_video_transcribe), qui assurent le routage vers chaque modèle et la modération des contenus visuels. Hébergé par le MEN (n8n.incubateur.education.gouv.fr).
